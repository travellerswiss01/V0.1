# Autonomous Company — V0.1

V0.1 proves the first autonomous-company loop:

1. Research candidate opportunities.
2. Score opportunities.
3. CEO selects the best next experiment.
4. Policy classifies risk.
5. Decision is persisted locally.
6. Dashboard exposes company state.
7. Optional AI CEO is available with OPENAI_API_KEY.

## Run

```bash
npm install
cp .env.example .env
npm run dev
```

Open http://localhost:3000.

## Scope

V0.1 is intentionally small. It does not execute payments, mass outreach, legal commitments, production deployments, or other irreversible actions automatically.

Next: V0.2 — real web research, stronger memory, GitHub product-building, and controlled execution.
